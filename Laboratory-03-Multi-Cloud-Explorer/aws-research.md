# AWS (Amazon Web Services) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform owned by Amazon. It provides different cloud services such as computing, storage, databases, networking, security, and more. AWS allows businesses and developers to use IT resources through the internet without needing to buy and maintain their own physical servers.

AWS was launched by Amazon in **2006**. One of its first major services was Amazon Simple Storage Service (Amazon S3), which was introduced in March 2006. AWS was created to provide scalable and reliable IT infrastructure that businesses could use when needed.

## Global Infrastructure

As of 2026, AWS has **39 geographic Regions and 123 Availability Zones** around the world. AWS Regions are located in areas such as North America, South America, Europe, Asia Pacific, Australia and New Zealand, the Middle East, and Africa. Availability Zones are separate locations inside a Region that help keep applications available and reliable.

## Cloud Management Console

The **AWS Management Console** is the web-based interface used to manage AWS resources and services. Through the console, users can create and manage resources, monitor services, check billing, and choose different AWS Regions. It provides access to more than 200 AWS services.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** — Provides virtual servers that users can use to run applications and websites.

2. **Amazon S3 (Simple Storage Service)** — A cloud storage service used to store and retrieve files, images, videos, backups, and other data.

3. **Amazon RDS (Relational Database Service)** — Makes it easier to create, operate, and manage relational databases in the cloud.

4. **AWS Lambda** — Allows users to run code without managing or maintaining servers. It is useful for applications that need to run automatically when an event happens.

## Three (3) Advantages

1. **Scalability** — AWS allows businesses to increase or decrease their cloud resources depending on their needs.

2. **Cost-effective** — Businesses can use cloud resources without buying expensive physical servers and other infrastructure upfront.

3. **Global Availability** — AWS has many Regions and Availability Zones around the world, allowing companies to provide services closer to their customers.

## Typical Enterprise Use Cases

Many types of companies use AWS, including **technology companies, banks, e-commerce businesses, media companies, healthcare organizations, startups, government agencies, and large enterprises**. They use AWS to host websites and applications, store and protect data, manage databases, analyze information, and develop new digital products.

AWS is useful for enterprises because it can provide computing resources quickly, support large numbers of users, and help companies scale their systems as their business grows. AWS customers include startups, enterprises, non-profit organizations, and governments.
