# Laboratory 01: Welcome to the Cloud

## Mission Overview
As a Junior Cloud Infrastructure Engineer Trainee at CloudNova
Technologies, this mission required completing an onboarding challenge
using the KillerCoda Playground. The goal was to practice working
inside a Linux environment, document technical work professionally, and
build a version-controlled Cloud Computing Portfolio on GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
1. Launched an Ubuntu 24.04 Playground on KillerCoda.
2. Created a new user account with sudo privileges and logged in.
3. Recorded the current username, working directory, and hostname.
4. Investigated the Linux distribution, kernel version, CPU info,
   memory, and disk space, and documented the findings in
   `system-information.md`.
5. Built a workspace folder structure (`workspace/projects`, `Notes`,
   `screenshots`) inside the home directory.
6. Created and wrote `about-me.md` inside the `Notes` folder.
7. Created a public GitHub repository (`CCM101-<username>`) and
   structured it with a root `README.md` and a
   `Laboratory-01-Welcome-to-the-Cloud` folder.
8. Documented the mission in this `README.md` file.
9. Captured and organized screenshots as evidence of each checkpoint.
10. Committed and pushed all work to GitHub.

## Linux Commands Used
- `sudo adduser` — create a new user account
- `sudo usermod -aG sudo` — grant sudo privileges
- `su -` — switch to another user account
- `whoami` — display current username
- `pwd` — display current working directory
- `hostname` — display system hostname
- `lsb_release -a` / `cat /etc/os-release` — check Linux distribution
- `uname -r` — check kernel version
- `lscpu` — check CPU information
- `free -h` — check memory usage
- `df -h` — check disk space
- `mkdir -p` — create directories (including nested ones)
- `nano` — create and edit files
- `cat` — display file contents
- `cd` — change directory

## Skills Learned
- Creating and managing Linux user accounts and permissions.
- Navigating the Linux file system and organizing directories.
- Gathering and documenting system information from the command line.
- Writing clear technical documentation using Markdown.
- Setting up and structuring a professional GitHub repository.
- Following a real-world onboarding workflow similar to that of a
  cloud infrastructure engineer.
