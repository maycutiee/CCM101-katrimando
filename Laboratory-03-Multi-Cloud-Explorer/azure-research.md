# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services such as virtual machines, storage, databases, networking, artificial intelligence (AI), and security. Azure allows businesses and developers to build, deploy, and manage applications through Microsoft's global network of data centers.

Microsoft officially launched Azure on **February 1, 2010**. It was created to help organizations move their applications and data to the cloud while supporting both Windows and Linux environments. Today, Azure is one of the world's leading cloud computing platforms.

## Global Infrastructure

Microsoft Azure has **more than 60 cloud regions** and **over 300 data centers** across the world. Many Azure regions also support **Availability Zones**, which are physically separate data centers within a region that improve reliability and availability. Azure is available in North America, South America, Europe, Asia Pacific, the Middle East, and Africa.

## Cloud Management Console

The **Azure Portal** is Microsoft's web-based management console for Azure services. It allows users to create and manage virtual machines, storage accounts, databases, networking, security settings, and other cloud resources. Users can also monitor resource performance, manage subscriptions, and view billing information through the portal.

## Four (4) Core Services

1. **Azure Virtual Machines (VMs)** — Provides virtual servers that allow users to run Windows or Linux applications in the cloud.

2. **Azure Blob Storage** — A cloud storage service used to store files, images, videos, backups, and other unstructured data.

3. **Azure SQL Database** — A fully managed cloud database service that makes it easy to build and manage SQL databases.

4. **Azure App Service** — A platform for building, deploying, and hosting web applications and APIs without managing servers.

## Three (3) Advantages

1. **Easy integration with Microsoft products** such as Windows Server, Microsoft 365, Active Directory, and SQL Server.

2. **High security and reliability** with built-in security features and a global network of data centers.

3. **Scalable and flexible**, allowing businesses to increase or decrease cloud resources based on their needs.

## Typical Enterprise Use Cases

Many organizations use Microsoft Azure, especially businesses that already use Microsoft products. These include banks, healthcare organizations, government agencies, schools, manufacturing companies, and large enterprises. Azure is commonly used to host business applications, manage databases, store files, support remote work, run virtual desktops, and build cloud-based solutions while integrating with Microsoft 365 and other Microsoft services.
